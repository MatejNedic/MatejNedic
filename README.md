### My main area of focus

#### Spring Cloud AWS
[Spring Cloud AWS](https://github.com/awspring/spring-cloud-aws) simplifies using AWS managed services in Spring and Spring Boot applications. It lets you work with services like SQS, SNS, S3, DynamoDB, Secrets Manager and Parameter Store using familiar Spring idioms and auto-configuration, so you can focus on your application instead of AWS SDK boilerplate.

Since 2026 I've been the Project Lead of Spring Cloud AWS.

#### Spring Data DynamoDB
[Spring Data DynamoDB](https://github.com/awspring/spring-data-dynamodb) brings the familiar Spring Data programming model to Amazon DynamoDB. It lets you define repositories and work with DynamoDB using the same Spring idioms you already know, cutting out the low-level boilerplate of the AWS SDK.
